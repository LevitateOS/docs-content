# @levitate/docs-content

Structured documentation content library for LevitateOS. This package provides TypeScript-typed documentation content that can be consumed by both the website and TUI documentation viewer.

## Installation

```bash
bun install
```

## Usage

```typescript
import { installContent, levitateContent } from '@levitate/docs-content';
```

## Development

```bash
# Type checking
bun run typecheck

# Linting
bun run lint

# Format
bun run format

# Run all checks
bun run check
```
